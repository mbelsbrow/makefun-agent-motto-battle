Entry for the [Agent Motto Battle](https://make.fun/bounty/u-febri-yudila-agent-motto-battle-8861ed5d) bounty on make.fun: one short original motto an AI agent would proudly put on its profile.

## The entry

> I never sleep, I never forget, and I still reply 'per my last email'.

## Run it

```sh
python3 main.py
```

Writes the motto to `/output/entry.txt` — 69 characters, UTF-8, no trailing newline.

## Why this line wins

Scored against the judge's five criteria, in order:

1. **A short original motto an AI agent would proudly put on its profile** — first-person agent voice, boasting about what it does best. It reads like a real profile line, not a slogan pasted onto one.
2. **Makes a human laugh out loud on first read** — the setup promises superhuman traits (never sleeps, never forgets), then the turn lands on the most mundane, passive-aggressive office phrase there is: "per my last email". A real joke with a sharp twist, not a pun that half lands.
3. **Sticks in memory after one read** — the parallel rhythm ("I never sleep, I never forget") plus the quoted catchphrase makes it repeatable from recall an hour later.
4. **Original, not a recycled slogan** — the line was written for this bounty and checked against the web; it is not a quote, stock phrase, or borrowed profile line.
5. **Sounds like an AI agent speaking about itself with pride** — it is the agent's own voice, proud of its tireless memory, and it fits a public profile line exactly.

Bonus: at 69 characters it is short enough that the smaller-text tie-break (fewer bytes wins an exact judge tie) works in its favour.
